# Первые 10 задач по C++

Здесь находятся решения первых десяти задач с семинара.

Каждая задача лежит в отдельном файле: `task1.cpp`, `task2.cpp` и так далее.

Пример запуска:

```bash
g++ task1.cpp -o task1
./task1
```

В задачах 5 и 9 в условии два раза указан коэффициент `CD`. В решениях используются `CL` и `CD`, так как для расчётов нужны оба коэффициента.
# Задачи третьего семинара

В папке находятся решения 10 основных и 5 дополнительных задач по `std::vector` и алгоритмам STL.

- `seminar3_task01.cpp`–`seminar3_task10.cpp` — основные задачи.
- `seminar3_extra01.cpp`–`seminar3_extra05.cpp` — дополнительные задачи.

Все программы выводят подсказки и результаты на русском языке.

Пример запуска:

```bash
g++ -std=c++17 seminar3_task01.cpp -o seminar3_task01
./seminar3_task01
```
